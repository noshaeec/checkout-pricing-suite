# BUG-001: VAT is rounded down instead of half-up

- **Requirement:** REQ-10 (and the half-up rounding rule at the top of the spec)
- **Severity:** Major
- **Found by test:** `tests/test_checkout.py::test_vat_rounds_half_up`

## Steps to reproduce
1. Check out one item: name "widget", price 100.10, quantity 1, no coupon, standard delivery.
2. Read `receipt.vat`.

## Expected result (from the spec)
Taxable amount = 100.10 + 60.00 shipping = 160.10. VAT = 15% of 160.10 = 24.015, which rounds half-up to 24.02.

## Actual result
`receipt.vat` is 24.01, and the total is 184.11 instead of 184.12.

## Notes
Smallest input: any amount whose VAT ends in exactly half a cent. It looks like the VAT is cut off instead of rounded. The error is one cent per order, but it affects every order that hits a half-cent.
