# BUG-002: Order of exactly R1000.00 gets 10% discount instead of 15%

- **Requirement:** REQ-04
- **Severity:** Major
- **Found by test:** `tests/test_discounts.py::test_volume_discount_at_boundaries[1000.00-150.00]`

## Steps to reproduce
1. Check out one item: name "widget", price 1000.00, quantity 1, no coupon, standard delivery.
2. Read `receipt.volume_discount`.

## Expected result (from the spec)
A subtotal of R1000.00 or more gets 15% off, so the discount is 150.00. The discounted subtotal is 850.00, shipping is free (850.00 is above 750.00), VAT is 127.50 and the total is 977.50.

## Actual result
`receipt.volume_discount` is 100.00 (10%). The total is 1035.00 instead of 977.50, so the customer is overcharged R57.50.

## Notes
Boundary bug: R1000.01 gets the correct 15%, but exactly R1000.00 does not. The code seems to treat "R1000.00 or more" as "more than R1000.00".
Severity reason: wrong amount on the receipt, silent, no workaround (see `docs/severity-levels.md`).
