# BUG-005: Coupon codes are case-sensitive

- **Requirement:** REQ-05
- **Severity:** Major
- **Found by test:** `tests/test_coupons.py::test_coupon_codes_are_not_case_sensitive` and `tests/test_coupons.py::test_freeship_is_not_case_sensitive`

## Steps to reproduce
1. Check out one item: name "widget", price 200.00, quantity 1, coupon "welcome5", standard delivery.
2. Observe the result.
3. Repeat with one item at 100.00 and coupon "freeship".

## Expected result (from the spec)
REQ-05 says coupon codes are not case-sensitive. "welcome5" must behave exactly like "WELCOME5": coupon discount 50.00, shipping 60.00, VAT 31.50, total 241.50. "freeship" must behave like "FREESHIP": shipping 0.00.

## Actual result
Both calls raise `InvalidCouponError` with the message "unknown coupon: welcome5" (and "unknown coupon: freeship"). A customer who types a valid code in lower case is refused.

## Notes
Only the exact upper-case spellings are accepted. Both lower-case codes were tested. Mixed case such as "Welcome5" was not tested, but the same cause would be expected.
