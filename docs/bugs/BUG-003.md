# BUG-003: Free shipping is decided on the original subtotal, not the discounted subtotal

- **Requirement:** REQ-08
- **Severity:** Major
- **Found by test:** `tests/test_shipping.py::test_discounted_subtotal_just_below_750_pays_shipping`

## Steps to reproduce
1. Check out one item: name "widget", price 833.32, quantity 1, no coupon, standard delivery.
2. Read `receipt.shipping`.

## Expected result (from the spec)
The 10% volume discount is 83.33, so the discounted subtotal is 749.99. That is below R750.00, so standard shipping costs R60.00. The total should be 931.49.

## Actual result
`receipt.shipping` is 0.00 (free). The total is 862.48, so the shop loses the shipping fee.

## Notes
The spec says the R750.00 threshold applies to the discounted subtotal (after the volume discount). The result looks as if the threshold is checked against the original subtotal of 833.32, which is above 750.00. The total is also affected by the VAT rounding bug (BUG-001), so part of the difference comes from that.
Severity reason: wrong amount on the receipt, silent, no workaround (see `docs/severity-levels.md`).
